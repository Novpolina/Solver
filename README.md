# Quadratic Equation Solver

Консольная программа на C++ для решения линейных и квадратных уравнений. Поддерживает действительные и комплексные корни, проверку входных данных, параметры командной строки и набор тестов.

## Сборка и запуск

```bash
make solve
./solve
```

Для сборки тестов:

```bash
make tests
./tests
```

Сгенерированная Doxygen-документация находится в каталогах `html` и `latex`.
